# Personas

## Personal Finance Manager

- **Context**: A signed-in person recording income, expenses, transfers, and AI-assisted captures for their own accounts.
- **Goal**: Trust the balances and history shown across the dashboard, accounts, and movement screens after saving a transaction.
- **Need**: Every screen that has already loaded should converge on the server's latest financial state without requiring a manual refresh.
- **Concern**: A dashboard total can appear updated while a selected account balance remains old, making it unclear whether money was actually recorded.

This is a workflow persona, not a separate authorization role. The task does not add roles, sharing, or multi-user access.
